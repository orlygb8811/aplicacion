# GradInk Studio

Aplicación Android para convertir imágenes de tatuajes en mapas de valores tonales por colores. Compilación mediante Android Gradle Plugin y GitHub Actions.

El código procesa las imágenes localmente dentro de una WebView. **Cada tono de gris tiene un color identificador**; los presets no equivalen a una calibración de tintas sobre piel.

Para instalar la beta, descargar el APK de la carpeta `releases` cuando haya terminado la compilación en Actions.

Verificación: compilar la versión 1.1 con GitHub Actions antes de distribuir el APK.
